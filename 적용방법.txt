eNVy 화면 적용 방법 (Windows / VS Code)

1. 서버가 실행 중이면 터미널에서 Ctrl+C로 종료하세요.
2. 기존 app.py를 프로젝트 폴더 밖에 복사해 백업하세요.
3. 압축을 풀고 이 폴더의 app.py와 static 폴더를 기존 eNVy 폴더에 복사하세요.
   app.py는 기존 파일을 교체합니다. static 폴더는 app.py와 같은 위치에 놓습니다.
   .venv, models, scan.py, requirements.txt는 기존 것을 사용합니다.

최종 구조:
eNVy/
  app.py
  scan.py
  static/
    index.html
    envy.png
  models/
    EMBER2024_PE.model
  .venv/

4. VS Code 터미널에서 실행하세요.
   .\.venv\Scripts\python.exe -m uvicorn app:app --reload --host 127.0.0.1 --port 8000

5. 브라우저에서 http://127.0.0.1:8000 접속 후 Ctrl+F5로 새로고침하세요.
   index.html을 직접 더블클릭하지 말고 서버 주소로 접속하세요.

6. 기존에 검사했던 where.exe로 결과가 동일한지 확인하세요.
   파일 드래그, 잘못된 확장자, 10 MiB 초과, 재검사도 확인하세요.

기존 app.py에 별도 변경 사항이 있다면 전체 교체 대신 다음만 적용할 수 있습니다.
  - FileResponse와 StaticFiles를 import 합니다.
  - app 생성과 BASE_DIR 선언 뒤에 추가:
    app.mount("/static", StaticFiles(directory=str(BASE_DIR / "static")), name="static")
  - 기존 home() 함수를 아래로 교체합니다(기존 HTMLResponse 지정도 제거).
    @app.get("/", response_class=FileResponse)
    def home():
        return FileResponse(BASE_DIR / "static" / "index.html")
  - /scan 응답 형식은 filename(문자열), score(숫자), verdict(문자열)를 유지합니다.

GitHub에 저장하려면:
  git add app.py static/index.html static/envy.png
  git commit -m "Add eNVy scanner interface"
  git push

이 패키지는 설치된 FastAPI와 모델을 그대로 사용하며 추가 패키지가 필요하지 않습니다.
결과 점수는 확률이나 정확도가 아닙니다. 기준값 0.5는 기존 시연 기준입니다.
실제 모델 실행은 이 제작 환경에서 재현하지 않았으며, 적용 후 본인 환경에서 확인하세요.
